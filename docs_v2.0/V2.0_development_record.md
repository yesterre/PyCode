## 2. 问题与解决方法

### P1-01：Windows 沙箱临时目录初始化失败（已处理）

修改前直接运行完整测试，使用 `tmp_path` 的测试出现 setup error；单独使用新目录运行 Scanner 测试仍出现同类错误，错误报告未能正常结束，两次执行手动中止。未取得完整错误堆栈或有效汇总，不能据此认定业务失败。

经授权在沙箱外、使用新的临时目录重跑，205 项现有测试全部通过（17.91 秒）。这是 CLI 迁移前的兼容基线；此时新增 Engine 和包导出已存在，但 CLI 尚未接入。后续测试同样在沙箱外运行，不引入 pytest 包装器或修改项目权限逻辑。

手动示例在沙箱内也出现明确 `PermissionError: [WinError 5]`，无法访问 `TemporaryDirectory` 刚创建的副本目录，清理同样被拒绝；授权在沙箱外执行相同示例后通过。首次失败留下的目录位于忽略的 `.pytest_tmp_v2_phase1_manual_demo`，未清理其他已有测试目录。

### P1-02：CLI 混合编排和展示（已迁移并通过回归）

原索引、图谱、问答和 Agent 命令同时承担调用与打印。新增 Engine 集中编排，CLI 只渲染返回结果；问答通过 `AnswerResult` 保留检索对象和证据，CLI 仍返回字符串。Artifact 错误提示保持兼容。

### P1-03：两种路径语义必须分别保留（已通过回归）

显式索引／图谱输出和普通 query 的 graph 路径沿用当前工作目录语义；Agent graph 路径按“绝对路径 → 当前工作目录下已有文件 → 项目内已有文件 → 原路径”解析。解析移至 Engine，不统一改为项目相对路径；工具仍执行项目内路径权限检查。

### P1-04：planner 副作用与内部状态写入（本阶段保留）

`plan_task()` 会更新传入 `AgentTask.task_type`。Engine 复用 `run_agent_task()` 每次创建任务，避免共享调用状态，不变更 planner 契约。Memory／Task DAG 可能写入 `.pclens`；关闭自动 Memory 提取不等于禁止全部内部状态工具。默认不运行测试、不改源代码、不提交 Git 的边界保持不变。

### P1-05：新测试对现有 Agent 行为的两个假设不准确（已修正并通过复测）

首次定向测试 43 passed / 2 failed：第二个隔离项目只有顶层 print，没有静态入口线索，因此不能要求入口检索返回非空证据；未授权的 `run_tests` 在 LLM action 校验阶段就被拒绝，不一定进入 Executor 并生成 ToolResult。

修正测试项目以包含独立入口；分别验证 `run_tests` 的规划阶段拒绝和一般非只读工具的 Executor policy 拒绝。保留对不执行工具、fallback Trace、授权参数传递的断言，不修改 Runtime／Policy 语义。

第二次定向测试 46 passed / 1 failed：在 `other.py` 中增加 main guard 仍不足以匹配现有 Query 的入口启发式，该查询按入口文件名或名为 main 的函数识别。最终将隔离项目入口命名为 `app.py`，保持不同项目使用不同文件名以检查证据不混用。此限制属于既有静态查询能力，不在 Phase 1 扩展。

### 模块职责检查结果

| 模块 | 输入／输出与职责 | 副作用／异常及处理决定 |
| --- | --- | --- |
| Scanner / Parser | 项目路径 → Python 文件 → FileInfo | 只读；保留路径、读取和 SyntaxError 异常 |
| GraphBuilder / Query | ProjectIndex → CodeGraph；图谱 → 节点／边 | 内存计算；不加入数据库或 HTTP 逻辑 |
| Retriever | 问题／目标 + index / graph → RetrievalResult | 读取有限源码上下文，保留现有算法 |
| Engine | 编排上述能力，返回领域对象 | index / graph 写产物；问答可能调用 LLM；不打印 |
| Runtime / Planner | 新 AgentTask + 配置 → AgentResult | 每次构造运行状态，沿用规划、观察、停止与降级语义 |
| Executor / Tools / Policy | 工具调用 → ToolResult | 统一参数校验、项目路径和测试授权；不绕过权限 |
| Trace / Context / Todo | 事件、证据和运行进度 | 保留现有结构，不提前实现持久化事件协议 |
| Memory / Task DAG | 项目辅助知识与跨会话任务 | 本地内部状态读写；不作为后台调度系统 |
| Storage | 领域对象 ↔ JSON 文件 | 创建父目录、写入产物；保留原格式和读取异常 |

### 4.4 Python API 与假 LLM CLI 手动验证

以下整段直接粘贴到 PowerShell。它复制示例源码到项目内临时目录，避免覆盖原示例的索引／Memory。`TemporaryDirectory` 在结束时清理自己创建的副本；父目录保留。假 LLM 仅返回固定文字，实际检索证据、图谱和工具执行仍使用 Core。

```powershell
@'
import shutil
import subprocess
import sys
import tempfile
from pathlib import Path
from pycode import AnswerResult, PyCodeEngine
from pycode.cli import ask_project, impact_project_target

class DemoLLM:
    def generate(self, prompt: str) -> str:
        return "offline demo answer"

scratch = Path(".pytest_tmp_v2_phase1_manual_demo").resolve()
scratch.mkdir(exist_ok=True)
with tempfile.TemporaryDirectory(prefix="run_", dir=scratch) as directory:
    project = Path(directory) / "demo_project"
    shutil.copytree(
        Path("examples/demo_project"), project,
        ignore=shutil.ignore_patterns(".pclens", ".git", "__pycache__", ".pytest_cache", ".pytest_tmp*"),
    )
    engine = PyCodeEngine()
    index = engine.build_index(project)
    assert index.files and not (project / ".pclens").exists()
    engine.index(project)
    graph = engine.graph(project)
    entries = engine.query(project, "entry")
    assert graph.nodes and entries
    client = DemoLLM()
    answer = engine.ask(project, "entry main", llm_client=client)
    impact = engine.impact(project, "services/user_service.py", llm_client=client)
    assert isinstance(answer, AnswerResult) and answer.evidence and impact.evidence
    preview = engine.run_agent(
        project, "entry main", plan_only=True, use_llm_planner=False,
        enable_memory=False, enable_memory_extraction=False,
    )
    assert preview.ok and not preview.tool_results
    run = engine.run_agent(
        project, "entry main", llm_client=client, use_llm_planner=False,
        enable_memory=False, enable_memory_extraction=False,
    )
    assert run.answer == "offline demo answer" and run.trace and run.tool_results
    assert all(result.tool != "run_tests" for result in run.tool_results)
    print("API evidence:", answer.evidence)
    print("Impact evidence:", impact.evidence)
    print("Agent:", run.stop_reason, run.trace.run_id)
    assert ask_project(project, "entry main", llm_client=client) == answer.answer
    assert impact_project_target(project, "services/user_service.py", llm_client=client) == impact.answer
    commands = [
        ["index", str(project)],
        ["graph", str(project)],
        ["query", "entry", str(project)],
        ["agent", str(project), "entry main", "--plan-only", "--rule-plan", "--show-context"],
    ]
    for args in commands:
        subprocess.run([sys.executable, "-m", "pycode.cli", *args, "--plain"], check=True)
    print("PHASE1_SMOKE_OK")
'@ | .\.venv\Scripts\python.exe -
```

通过标准：无 traceback，出现真实文件／图谱证据、Agent run ID、CLI 输出，以及最后的 `PHASE1_SMOKE_OK`。索引和图谱只写副本的 `.pclens`。API Agent 显式关闭 Memory；CLI 计划预览沿用默认内部状态行为，范围也限定在临时副本。

若缺少示例路径，确认当前目录；若 import 失败，确认虚拟环境已安装项目；若断言失败，先运行 4.2 查看具体回归结果。
